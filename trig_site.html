정의

일반각

평면 위 두 반직선 OX, OP에 대하여 ∠XOP의 크기는 OX(시초선)의 위치에서 OP(동경)가 회전한 양으로 정한다.

반시계방향: 양(+)의 방향
시계방향: 음(−)의 방향
동경 OP가 나타내는 일반각 360° × n + a°   (n은 정수) 같은 동경이라도 회전 수(n)에 따라 각의 크기는 무수히 많다.
  • 1390° = 360°×1+30°, 750°=360°×2+30°, −330°=360°×(−1)+30°  → 모두 같은 동경
  • 2좌표평면에서 시초선은 보통 x축의 양의 부분

새로운 단위

호도법

반지름 r인 원에서 길이 r인 호 AB에 대한 중심각의 크기 a°는
r : 2πr = a° : 360° r에 관계없이 a° = 180°/π로 항상 일정하다.
이 일정한 각 180°/π를 1라디안이라 하고, 이를 단위로 각을 나타내는 방법을 호도법이라 한다. 1라디안 = 180°/π    1° = π/180 라디안
45° = 45×π/180 = π/4
−5/6π = −5/6π × 180°/π = −150°
생각 톡톡

π는 몇 도(°)일까?  |  라디안은 "단위가 없는 것처럼" 실수로 쓴다 — 각도에 단위가 없다는 것은 무엇을 의미하는가?

부채꼴의 호의 길이와 넓이

l = rθ, S = ½r²θ

반지름 r, 중심각 θ(라디안)인 부채꼴의 호의 길이 l과 넓이 S:
l = rθ     S = ½r²θ = ½rl
※ θ의 단위는 반드시 라디안!

예) r=3, θ=π/6 → l = 3×π/6 = π/2,   S = ½×9×π/6 = 3π/4

SECTION 02

삼각함수

일반각으로 확장된 sin θ, cos θ, tan θ의 정의

확장

삼각함수의 정의

중학교: 0°~90°의 삼각비는 직각삼각형의 크기와 무관하게 일정했다 (∠A 공통인 △ABC, △ADE에서 sinA, cosA, tanA 값은 서로 같다).

고등: 이 개념을 일반각으로 확장한다.
원점 O 중심, 반지름 r인 원 위의 점 P(x,y), 동경 OP가 나타내는 일반각 θ에 대하여 sinθ = y/r   cosθ = x/r   tanθ = y/x (x≠0) 이 셋을 통틀어 θ에 대한 삼각함수라 한다.
생각 톡톡

동경이 x축 위에 있을 때, sinθ의 값은 얼마일까?

단위원 위의 정의

sinθ = y/r, cosθ = x/r, tanθ = y/x

r의 값에 관계없이 θ의 값에 따라 y/r, x/r, y/x는 각각 하나로 정해진다.

예제 1 — P(3, −4)를 지나는 동경이 나타내는 각 θ
OP = √(3²+(−4)²) = 5
sinθ = −4/5, cosθ = 3/5, tanθ = −4/3
예제 2 — θ = 4/3π일 때 (반지름 1인 원에서)
OH=cos(π/3)=1/2, PH=sin(π/3)=√3/2, 제3사분면이므로 P(−1/2, −√3/2)
sinθ = −√3/2, cosθ = −1/2, tanθ = √3
TOK 포인트

sin, cos, tan 기호는 17~18세기에 여러 수학자(핀케, 건터, 오일러)를 거쳐 정착됐다. 표기법의 발명과 개념의 발견은 어떻게 다른가?

부호

삼각함수 값의 부호

동경 위의 점 P(x,y)의 부호에 따라 결정되므로, θ를 나타내는 동경이 위치한 사분면에 따라 정해진다.

  • 1제1사분면: sin+, cos+, tan+ (모두 양수)
  • 2제2사분면: sin+, cos−, tan−
  • 3제3사분면: sin−, cos−, tan+
  • 4제4사분면: sin−, cos+, tan−
110°는 제2사분면 → sin110°>0, cos110°<0, tan110°<0
10/3π는 제3사분면 → sin<0, cos<0, tan>0

삼각함수 사이의 관계

tanθ = sinθ/cosθ,   sin²θ+cos²θ=1

단위원(반지름 1) 위의 점 P(x,y): x=cosθ, y=sinθ
tanθ=y/x 이므로 tanθ = sinθ/cosθ
x²+y²=1 이므로 sin²θ+cos²θ=1
예제 3 — θ가 제2사분면, sinθ=4/5
cos²θ=1−16/25=9/25, 제2사분면이므로 cosθ<0 → cosθ=−3/5, tanθ=−4/3
예제 4 — sinθ+cosθ=1/2일 때 sinθcosθ = ?
양변 제곱: 1+2sinθcosθ=1/4 → sinθcosθ=−3/8

삼각함수의 그래프

y = sin x, y = cos x — 주기함수의 성질과 변환

그래프

사인함수·코사인함수의
그래프

단위원 위의 점 P(x,y): sinθ=y, cosθ=x
θ가 변할 때 sinθ, cosθ의 값의 변화는 각각 점 P의 y좌표, x좌표의 변화와 같다.
  • 1정의역: 실수 전체, 치역: {y|−1≤y≤1}
  • 2y=sinx: 원점 대칭 → sin(−x) = −sinx
  • 3y=cosx: y축 대칭 → cos(−x) = cosx
  • 4주기 2π인 주기함수 → sin(x+2nπ)=sinx, cos(x+2nπ)=cosx
생각 톡톡

y=sinx와 y=cosx의 최댓값과 최솟값은 각각 얼마일까?

그래프 & 변환

y = sinx, y = cosx

함수치역주기
y = 2sinx{y|−2≤y≤2}2π
y = ⅔cosx{y|−2/3≤y≤2/3}2π
y = cos2x{y|−1≤y≤1}π
y = sin(x/2){y|−1≤y≤1}4π

y=sin(ax), y=cos(ax)의 주기는 2π/|a| (a≠0)

변환

그래프의 평행이동

y=f(x−a)+b: y=f(x)를 x축으로 a, y축으로 b만큼 평행이동 y = sin(x−π/6)+1 → y=sinx를 x축으로 π/6, y축으로 1만큼 이동. 치역 {y|0≤y≤2}, 주기 2π
y = cos(x−π/3)−1 → 치역 {y|−2≤y≤0}, 주기 2π
TOK

스위스 베른의 미술관(그림)은 사인함수 그래프를 본떠 설계됐다. 수학적 곡선이 "아름답다"고 느껴지는 것은 보편적 감각인가, 문화적으로 학습된 것인가?

π만큼의 이동 · 대칭

sin(π±x), cos(π±x), sin(π/2±x), cos(π/2±x)

공식결과
sin(π+x)−sinx
cos(π+x)−cosx
sin(π−x)sinx
cos(π−x)−cosx
sin(π/2+x)cosx
cos(π/2+x)−sinx
sin(π/2−x)cosx
cos(π/2−x)sinx
유도: y=sinx, y=cosx의 그래프를 x축으로 −π(또는 −π/2)만큼 평행이동하면 위 공식이 그래프의 겹침으로 확인된다.
sin(π−x) = −sin(−x) = sinx  (π+x 공식에 x 대신 −x 대입)

탐구 · 논쟁

sin(2/3π)를 은우는 sin(π/2+π/6)으로, 수연이는 sin(π−π/3)으로 구했다. 두 방법 모두 옳은가? — 답은 √3/2로 동일. 같은 값에 도달하는 서로 다른 경로들은 수학적으로 "같은 증명"인가?

03 삼각함수의 그래프

문제 1 · 2 · 3 · 4 · 5 · 6

1
문제 1★☆☆
다음 삼각함수의 값을 구하시오.
(1) sin(−π/6)   (2) cos(9/4π)   (3) sin(5/3π)   (4) cos(23/6π)
▼
정답

(1) −1/2  (2) √2/2  (3) −√3/2  (4) √3/2

풀이

(1) sin(−π/6) = −sin(π/6) = −1/2 (2) cos(9/4π) = cos(2π+π/4) = cos(π/4) = √2/2 (3) sin(5/3π) = sin(2π−π/3) = sin(−π/3) = −sin(π/3) = −√3/2 (4) cos(23/6π) = cos(2π+11/6π) = cos(11/6π) = cos(−π/6) = cos(π/6) = √3/2

2
문제 2★☆☆
함수 y=⅔cosx의 치역과 주기를 구하고, 그래프를 그리시오.
▼
정답

치역: {y|−2/3≤y≤2/3},  주기: 2π

풀이

−1≤cosx≤1이므로 −2/3≤⅔cosx≤2/3 → 치역 {y|−2/3≤y≤2/3} ⅔cosx=⅔cos(x+2π)이므로 주기는 2π y=cosx의 그래프를 y축 방향으로 ⅔배 축소한 모양

3
문제 3★★☆  함수 y=sin(x/2)의 치역과 주기를 구하고, 그래프를 그리시오.
▼
정답

치역: {y|−1≤y≤1},  주기: 4π

풀이

치역은 sinx와 같이 {y|−1≤y≤1} 주기 = 2π/|1/2| = 4π — y=sinx보다 가로로 2배 늘어난 그래프

4
문제 4★★☆  함수 y=cos(x−π/3)−1의 치역과 주기를 구하고, 그래프를 그리시오.
▼
정답

치역: {y|−2≤y≤0},  주기: 2π

풀이

−1≤cos(x−π/3)≤1에서 −2≤cos(x−π/3)−1≤0 → 치역 {y|−2≤y≤0} y=cosx를 x축으로 π/3, y축으로 −1만큼 평행이동한 것이므로 주기는 2π

5
문제 5★★☆  다음 삼각함수의 값을 구하시오.
(1) sin(5/4π)   (2) cos(7/6π)   (3) sin(5/6π)   (4) cos(2/3π)
▼
정답

(1) −√2/2  (2) −√3/2  (3) 1/2  (4) −1/2

풀이

(1) sin(5π/4)=sin(π+π/4)=−sin(π/4)=−√2/2 (2) cos(7π/6)=cos(π+π/6)=−cos(π/6)=−√3/2 (3) sin(5π/6)=sin(π−π/6)=sin(π/6)=1/2 (4) cos(2π/3)=cos(π−π/3)=−cos(π/3)=−1/2

6
문제 6 〔탐구〕★★★  은우: "sin(π/2+π/6)으로 구하면 되겠네."   수연: "sin(π−π/3)로 구해도 되는데?"
(1) sin(2/3π)의 값을 두 학생의 방법으로 각각 구하시오.
(2) cos(3/4π)의 값을 여러 가지 방법으로 구하고, 자신의 방법을 설명하시오.
▼
정답

(1) 두 방법 모두 √3/2  |  (2) −√2/2

풀이

(1) 은우: sin(π/2+π/6) = cos(π/6) = √3/2    수연: sin(π−π/3) = sin(π/3) = √3/2 — 두 방법 모두 결과가 같음을 확인 (2) 방법1: cos(3π/4)=cos(π−π/4)=−cos(π/4)=−√2/2    방법2: cos(3π/4)=cos(π/2+π/4)=−sin(π/4)=−√2/2 — 서로 다른 공식이라도 결과는 항상 일치
