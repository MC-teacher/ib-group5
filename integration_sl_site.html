Concept: Areas under curves can be approximated by the sum of areas of rectangles which may be calculated even more accurately using integration.

Integration (적분)

If you are given the gradient function \(f'(x)\), you can find the function \(f(x)\) by 'undoing' the differentiation. This process is known as integration. $$f'(x)=2x\ \Rightarrow\ f(x)=x^2+c,\qquad\int2x\,dx=x^2+c$$ The \(dx\) indicates that the variable you are integrating with respect to is \(x\), just as in \(\frac{dy}{dx}\).
$$\int x^n\,dx=\frac{1}{n+1}x^{n+1}+c\qquad(n\in\mathbb Z,\ n\ne-1,\ c\in\mathbb R)$$
기억법: 지수를 1 올리고, 올린 지수로 나눈다. 미분 \((x^n)'=nx^{n-1}\)의 정반대 순서!
Tip: Note the condition \(n\ne-1\), which ensures that you are not dividing by zero. You will see how to integrate \(x^{-1}\) in Chapter 21.
WE 10.1If \(f'(x)=x^{-4}\), find an expression for \(f(x)\).
Integrate to find f(x)\(f(x)=\int x^{-4}\,dx\)
Use the rule\(=\dfrac{1}{-4+1}x^{-4+1}+c=-\dfrac13x^{-3}+c\)
\(f(x)=-\frac13x^{-3}+c\)

KEY POINT 10.1

As with differentiation, the basic rule is unaffected by multiplication by a constant, and it can be extended to deal with sums.
$$\int\left(ax^n+bx^m+\dots\right)dx=\frac{a}{n+1}x^{n+1}+\frac{b}{m+1}x^{m+1}+\dots+c$$
where \(a, b\) and \(c\) are real constants and \(n,m\in\mathbb Z,\ n,m\ne-1\).

3 = 3x⁰상수 \(k\)의 적분은 바로 \(kx\)로 써도 된다.

Definite integration

So far you have been carrying out indefinite integration – it is indefinite because you have the unknown constant each time. A similar process, called definite integration, gives a numerical answer – no \(x\)s and no unknown constant. The upper and lower limits are written at the top and bottom of the integral sign.
